# DTF `rlp_decode.decodeTxFields`: cut points, assertions, budgets (S7 step 3)

## Cut points (162)

- The map's 153 (`zmap show f_8000050c`, join cuts on): entry, 50 loop heads (byte loops of the
  field helpers, one block each), 87 call return sites, 15 join cuts.
- The five jump-table targets (`.jumpInd` leaves from `0x80000574` must end at a cut).
- Three hand-placed cuts (ledger `assertion` items):
  - `0x80000574`, the jump-table load: the executor reads rodata only at literal addresses, so the
    table word `0x80110050 + 8·t` is made region 4 (8 read-only bytes);
  - `0x80002138`, the store of a versioned hash into the `txHashList` buffer (`a0` = slot, 32 B);
  - `0x80002434`, the store of an `AuthorizationTuple` into the `txAuthList` buffer (0x90 B).
  The executor stores only at constant offsets of a region.

Runs: 162 `sym_run`s, 486 leaves, all evaluate (fuel 300); `Runs.lean` builds in 218 s (all runs
together; the 60 s per-run limit of the plan's last assumption is not approached, so no further
hand-placed cut was needed).

## Callee summaries for `decodeItem` (measured, not used)

`runWith` with F3's `decodeItem` summary from `0x80000588`: with the map's return sites kept it
passes the first call and stops at the next cut (1 leaf); with the return sites of the legacy arm's
first ten calls removed it returns `none`. Every field reuses the outcome slot `S-0x90`, and the
`rest` registers after one call hold `rest + consumed` read from that slot, so the second call's
state mentions the bytes the call writes (`CallRec.okB` fails). Summaries would need fresh symbolic
writes instead of a havocked `mem0` (a change to `Sym/Summary.lean` and `runWith_sound`); the
return-site cuts stay.

## Shapes (`Regions.lean`, generated by `shape.py`)

`python3 OPEN/DTF/shape.py <elf> <cut pcs> --lean` prints the `table` rows: a forward analysis of
the instructions (abstract values: entry-`sp`-relative, result/allocator-object-relative, the vtable
word, payload pointers tagged with the number `k` of top-level items consumed, `rest` lengths,
`decodeItem` consumed lengths; frame slots at 8-byte granularity; calls clobber the ABI registers
and the callee's outcome/rest/header ranges). Per cut: the registers/slots that hold pointers (the
cut's `SState` overrides and known facts, stated by `ShapeOk`), the arms reaching it, where the
latest `rest` slice is (`RestOk`), and for a return site the same at the call instruction.

## Assertions (`Cuts.lean`)

`PlainA` = pc, `Common`, `ShapeOk`, `ArmOk`, `RestOk`, `Extra`; `RetA` = call-site predicate at the
call machine and the callee's `Post`; `ACut` = the disjunction (only `0x80002a6c` is both a return
site and a jump target). `Extra`: `0x80000574` the table address, `0x80002138`/`0x80002434` the
buffer slot (RAM, present, from `Priv`), `0x800011f8` the written result (`Done`).

### Design for items 1, 2, 4 (not implemented; next step)

What the code does per scalar field (arm 4, item 0 = `chainId`, `0x800005dc..0x80000648`):
`decodeItem(S-0x90, s6 = rest ptr, s5 = rest len)`; outcome at `S-0x90`: payload ptr `-0x90`,
payload len `-0x88`, `isList` byte `-0x80`, consumed `-0x78`, error `-0x70`. Error or `isList`
→ `0x800011f0` (code 3); `rest += consumed` (`s6`, `S-0x220`), `len -= consumed` (`s7`,
`S-0x218`); `len > 8` → `0x800011f0`; then the byte loop `0x80000634` folds
`s10 = s10 << 8 | byte` over the payload. So after field `k` the value sits in a callee-saved
register (or a frame spill) as `be (itemPayload k)`, and every later `decodeItem` keeps it.

Proposed conjuncts (one generic form, a new column of the `shape.py` table):

* `FieldsOk σ m (fs : List (Loc × FieldVal))`, `FieldVal = (k, kind)` with kind `u64`,
  `nonce` (clamped), `u128lo`/`u128hi`, `u256 i` (limb `i`), `addrTag`, `bytesPtr`/`bytesLen`:
  `loc.word σ m = w (fieldWord kind (itemAt k σ.payload))`, `itemAt k` = the payload of the
  `k`-th top-level item (defined like `skip`). `shape.py`: give `('inp', k)` payload pointers the
  item index they point into, and add abstract values `('acc', k, n)` (the byte loop's
  accumulator over the first `n` payload bytes of item `k`) and `('fld', k, kind)`.
* `ChecksOk σ k`: for `i < k`, item `i` decodes (`skip`), is a string (`isList = false`) and
  passes its helper's length test (`armKinds t` lists the helper per field). Then a lemma
  `body_prefix`: `ChecksOk` for all fields of arm `t` and the `FieldsOk` values give
  `decode t payload = some tx` with `tx`'s fields equal to `fieldWord`s — the bridge `Done` needs.
* Byte-loop heads (`Inner.be`): `cur`/`end` inside item `k`'s payload, `end - cur ≤ 32`, and the
  accumulator register `= be (first (cur - start) bytes)`.

Leaves first affected: the success write `0x80002dc4 → 0x800011f8` (`Done`), and every
`at`-exit leaf (class `cut ite`, 268): `leaf_auto` stops at `if pc = entry` in `mkCut` (an
`@[zesu_simp]` unfolding of `entry` should let it reach `ACut`; not tried), after which a generic leaf theorem
(like `cut_plain`: `Common` kept by `SameOutside (InWritable …)`, `ShapeOk`/`RestOk` from the
leaf's symbolic registers) is the natural next tool; it should be written against the assertion
with these conjuncts, not before.

## Open: the success write `80002dc4_0` (step 4, open assertion items 1, 2, 4)

payload = some tx` and `TxAt m res tx` (every scalar field's bytes, the `data` copy, the access

`noExtra` targets).

### Stage 1 (generic carry, table empty)

State (`Cuts.lean`): `FieldVal` (item `k`) = `ptr`/`len` (`decodeItem`'s words), `num k n i`
(limb `i` of `numVal n p b`: `be b`, or `2^(8n) - 1` when `p > n`; nonce/u64 `n = 8`, u128 `16`,
u256 `32`), `nz` (tag: `p ≠ 0`), `raw k o n` (payload bytes `o..o+n-1` as the word's low bytes:
the address copy), `acc k n i cur fin` (byte loop: `p ≤ n`, cursor register `cur` at payload byte
`j < p`, `fin` at the end, value limb `i` of `be` of the first `j` bytes; the only kind that
mentions the machine, `FieldVal.free`). A `Field` is `⟨loc, arms, v⟩` (`arms`: the guard, empty =
every arm; one location holds a different item per arm at merged cuts). `FieldsOk σ m fs` = every
entry whose guard holds (`ArmOk`) has `v.Holds` at `loc` (`∀ c h p`, item `k` decodes →
`v.At`). `PlainA` ends with `FieldsOk σ m (cutFields d.pc)`; `SiteA` already had
`FieldsOk σ m (siteFields r)`. `cutFieldsTable` is empty.

Carry (`Gen.lean`, `fieldsCarry src d l fs`, sound by `fieldsCarry_sound`; `src = srcFields d`:
a plain source's `cutFields` row at `loc.sym`, a return site's call-site row of machine-free
values at kept locations, `keptSym`/`keptPtr`, `siteKeeps`): an entry passes when its `loc` is
`fine` and one of
- vacuous: the source's arms are nonempty and none is in the entry's guard (`armsOff`);
- kept: a free source value with the same `FieldVal`, guard implied (`guardOk`: source guard
  empty, target guard ⊆ it, or source arms ⊆ it), and the same symbolic value;
- from the source's outcome at `ko` (`fieldFrom`, `advOf`): `len`, `ptr`; `num`/`nz`/`raw` = 0
  with the condition `len = 0`; `num` = clamp literal with `n <u len`; `nz` = 1 with `len ≠ 0`
  (`nonzero`: `≠ 0` or `= q ≠ 0`); `acc` = 0 at a loop entry (cursor = pointer word, end =
  pointer + `len`, `len ≠ 0`, `lenBound ≤ min n 32`);

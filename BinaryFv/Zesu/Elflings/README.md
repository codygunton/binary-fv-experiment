# Elflings

`GeneratedLevel1.lean` contains generated identifiers for the six reviewed immediate function
instances and their exact production-ELF entries, exits, and execution ranges.

`GeneratedLevel2.lean` names the 22 reviewed immediate children using their source function and
callsite identities. It records exact entries, exits, parent instances, instruction counts, and
owned/execution PC ranges; these are artifact facts, not contract proofs.

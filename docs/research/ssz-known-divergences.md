# Reviewed SSZ decode divergences

`KnownBug` names fixed differences between the pinned Zesu endpoint and pinned EVM-Sail Lean. It
does not imply that Zesu is wrong whenever the two disagree: EIP-8025 is still Draft, and two
fixtures below show EVM-Sail revision choices that differ from the current EIP text.

| Lean constructor | Executable witness | Zesu `e5f8c13` | EVM-Sail `d0e4aabd` | Current EIP-8025 |
|---|---|---|---|---|
| `chainIdZeroNormalization` | `chain-id-zero.ssz` | maps zero to one at `ssz.zig:405` | retains the decoded `uint64` at `stateless_input.sail:985` | `build_chain_config` retains its argument; EVM-Sail matches |
| `legacyRequestTableArity` | `legacy-requests.ssz` | accepts any aligned table with at least three fields at `ssz.zig:238-241` | requires the five-field 20-byte container at `stateless_input.sail:458,503-507` | currently declares three fields; Zesu matches |
| `legacyPayloadSize` | `legacy-payload.ssz` | accepts 528- and 540-byte payloads at `ssz.zig:263-306` | requires 540 bytes at `stateless_input.sail:460,470-474` | currently has the 528-byte shape without slot number; Zesu matches |
| `futureForkActivation` | `future-activation.ssz` | parses but does not apply the activation values at `ssz.zig:188-200` | rejects a block/timestamp before activation at `stateless_input.sail:974-983` | explicitly checks `_is_activation_active`; EVM-Sail matches |
| `extraDataLength` | `extra-data-33.ssz` | copies the complete span at `ssz.zig:318` | enforces 32 bytes at `stateless_input.sail:486` | `ByteList[MAX_EXTRA_DATA_BYTES]`, where the maximum is 32; EVM-Sail matches |
| `publicKeyCount` | `public-key-overflow.ssz` | accepts every packed 65-byte element at `ssz.zig:358-367` | limits the count to 2^15 at `stateless_input.sail:547-553` | currently sets `MAX_PUBLIC_KEYS = 2^20`; this witness is EIP-valid and Zesu matches |
| `versionedHashCount` | `versioned-hash-overflow.ssz` | accepts every packed 32-byte hash at `ssz.zig:225-230` | limits the count to 4096 at `stateless_input.sail:555` | sets the same 4096 bound; EVM-Sail matches |

The fixtures are generated by `tools/make_minimal_ssz.py`. `nix/targets.nix` runs each against the
production RV64 ELF and the independent native Zig source probe and requires byte-identical Zesu
observations. `tests/evm-sail/DifferentialSmoke.lean` executes the extracted Lean decoder: it checks
the exact zero-chain result exception and requires EVM-Sail rejection for every accept-domain
fixture. A changed block-number observation is the negative test for the common-result checker.

EIP reference: [EIP-8025](https://eips.ethereum.org/EIPS/eip-8025), especially “SSZ objects” and
“SSZ schemas.” Its Draft status is why this table records which implementation each current clause
supports rather than treating the EIP as an unquestionable oracle.

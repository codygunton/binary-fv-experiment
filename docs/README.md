# Documentation

`evaluations/` contains durable, reviewed records explaining target selection and evidence. The
historical target evaluation retains tiny-SHA3/miniz measurements even though those targets are no
longer built.

`research/` contains investigated designs that are worth retaining but are not active work. The
agent-coordination note records the parked design for durable, auditable lead/worker notifications.

Agent plans live in ignored `docs/ai/`, indexed by `docs/ai/PROJECTS.md`; they are workstream state,
not repository documentation. The active workstream summary remains in ignored root `STATUS.md`.
